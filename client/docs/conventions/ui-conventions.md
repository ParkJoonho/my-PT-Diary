# UI 컨벤션

## 디자인 기준

홈 디자인의 1차 기준은 `docs/migration/home-design-spec.md`다. 홈에서 진입하는 독립 기능은 각 feature의 책임 문서와 QA 문서를 함께 기준으로 삼는다.

원본 스냅샷은 시각 비교와 코드 추출 참고용으로만 사용한다. 스냅샷 파일을 직접 가져오지 않는다.

## 시각 디자인 보존

첫 홈 마이그레이션에서는 원본 디자인을 보존한다. 다만 코드 소유권은 홈 화면 배치와 독립 기능을 분리하는 feature 구조를 따른다.

- 배경: `#F4F5F7`
- 포인트 색상: `#FF6A33`
- 카드: 흰색, 둥근 모서리, 약한 그림자
- 주요 텍스트: `#00192B`
- 보조 텍스트: `#6B7280`
- 흐린 텍스트/아이콘: `#8E8E8E`, `#B8C1CC`
- 목표 폰트: Pretendard

## Apps in Toss 상단 헤더

PT Diary의 커스텀 상단 헤더를 렌더링하지 않는다. 상단 헤더 역할은 Apps in Toss 기본 헤더가 맡는다.

즉 아래 항목을 지킨다.

- `AppHeader`를 옮기지 않는다.
- `GlobalHeader`를 옮기지 않는다.
- 더보기/닫기 버튼을 중복으로 렌더링하지 않는다.

## `미구현` 뱃지

`미구현`은 원래 UI는 그대로 보이지만 아직 동작이 연결되지 않았다는 뜻이다.

해야 할 것:

- 섹션 제목, 탭 라벨, 카드 제목, CTA 텍스트 옆에 작은 뱃지를 붙인다.
- 뱃지는 조용하고 작게 보이게 한다.
- 아직 연결되지 않은 컨트롤/카드/기능에 사용한다.

권장 뱃지 스타일:

```text
라벨: 미구현
글자 크기: 10
글자 굵기: 600
글자 색상: #FF6A33
배경: #FFF0EA
둥근 정도: 999
좌우 여백: 6-8
상하 여백: 3-4
```

하지 말아야 할 것:

- 카드나 화면 전체를 큰 대체 화면으로 바꾸지 않는다.
- 원본 디자인을 숨기지 않는다.
- 강한 경고색을 사용하지 않는다.
- 뱃지가 시각적 중심이 되게 만들지 않는다.

## 아이콘

시각적 일관성이 중요하면 `src/shared/components/icons`에 옮긴 `react-native-svg` 아이콘을 우선 사용한다. 단, `react-native-svg`는 Granite와 같은 버전 한 벌만 사용해야 한다.

스케폴딩 단계에서는 `@expo/vector-icons`를 피한다. 원본 화면에서 Expo 아이콘을 사용했다면 아래 방식 중 하나로 대체한다.

- 옮겨온 SVG 에셋 또는 컴포넌트
- 시각적 일치가 중요하지 않은 경우 간단한 텍스트 기호
- chevron이나 점처럼 단순한 요소는 React Native `View` 조합

## 이미지

React Native 기본 `Image`를 사용한다.

`expo-image`는 사용하지 않는다.

## 스타일링

React Native `StyleSheet.create`를 사용한다.

Tailwind나 NativeWind를 도입하지 않는다.

스타일은 가능하면 컴포넌트 가까이에 둔다. 여러 곳에서 실제로 공유되는 토큰이나 헬퍼만 `src/shared`로 뺀다.
