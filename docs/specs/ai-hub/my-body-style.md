# 나의 몸매 & 스타일

작성일자: 2026-07-28

## 1. 문서 목적

체형 분석 결과를 소비하는 후속 기능인 `/my-body-style` 화면을 별도 기능으로 정리한다.

## 2. 원본 구현 기준

| 구분 | 내용 |
| --- | --- |
| 화면 라우트 | `/my-body-style` |
| 화면 파일 | `app/my-body-style.tsx` |
| 예측 API | `POST /api/ai/predict-body` |
| 스타일 추천 API | `POST /api/ai/style-recommendation` |
| 의존 데이터 | 사용자 프로필 사진, 전신 사진, 최신 body 분석 기록 |

## 3. 기능 범위

- 프로필 사진 등록
- 전신 사진 등록
- 1/3/6개월 몸매 예측
- 최신 체형 분석 기반 스타일 추천
- 네이버 쇼핑 검색 키워드 링크

## 4. 요구사항 및 원본 구현 현황

| ID | 요구사항·기대 동작 | 원본 구현 판단 | 현재 확인 내용 | 근거 파일 |
| --- | --- | --- | --- | --- |
| MBS-001 | 사용자는 프로필/전신 사진을 저장할 수 있어야 한다. | 구현됨 | 사진을 data URI로 사용자 프로필에 저장한다. | `app/my-body-style.tsx` |
| MBS-002 | 전신 사진이 있으면 몸매 예측을 실행할 수 있어야 한다. | 구현됨 | 전신 사진이 없으면 예측 버튼이 비활성화된다. | `app/my-body-style.tsx`, `server/ai-routes.ts` |
| MBS-003 | 예측은 1/3/6개월 단위로 제공돼야 한다. | 구현됨 | 화면에 기간 선택 탭이 있다. | `app/my-body-style.tsx` |
| MBS-004 | 스타일 추천은 최신 body 분석 결과를 이용해야 한다. | 부분 구현 | 최신 분석을 조회하지만 사용 필드 구조가 실제 저장 구조와 맞지 않을 가능성이 크다. | `app/my-body-style.tsx`, `server/ai-routes.ts` |
| MBS-005 | 추천 코디는 실제 검색 가능한 상품 키워드로 연결돼야 한다. | 구현됨 | 네이버 쇼핑 검색 URL을 연다. | `app/my-body-style.tsx` |

## 5. 원본 구현에서 확인된 결함

| ID | 항목 | 현재 문제 |
| --- | --- | --- |
| MBS-BUG-001 | 로그인/프로필 의존성 큼 | 현재 구조는 사용자 프로필 사진 저장 기능이 전제다. |
| MBS-BUG-002 | 최신 body 분석 데이터 참조 불안정 | 화면은 `latestBodyAnalysis?.data` 또는 `analysis_data`를 읽는데 실제 저장 구조는 `rawResult` 중심이다. |
| MBS-BUG-003 | 스타일 추천 입력 구조 불일치 | 서버는 `shoulders`, `waist`, `hips`, `overallAssessment` 같은 필드를 기대하지만 체형 분석 결과 구조와 직접 맞지 않는다. |
| MBS-BUG-004 | 예측 입력의 운동 기록 활용 약함 | `predict-body`는 운동 기록을 받을 수 있지만 화면 호출은 전신 사진과 개월 수 위주다. |
| MBS-BUG-005 | 현재 `ai-pt` 아키텍처와 거리 있음 | 우리 앱은 아직 원본의 사용자 프로필/인증 체계 자체를 옮기지 않았다. |

## 6. 마이그레이션 판단

| 항목 | 판단 |
| --- | --- |
| 마이그레이션 우선순위 | 낮음 |
| 이유 | 원본 구현은 있으나, 체형 분석 본체가 아니라 후속 소비 기능이고 사용자 프로필 저장 의존성이 크다. |
| 선행 필요 조건 | 체형 분석 본체, 분석 이력, 사용자 프로필/사진 저장 정책 정리 |

## 7. 이번 설계 기준 보정 포인트

| 항목 | 설계 기준 |
| --- | --- |
| 사용자 데이터 구조 | `x-user-key` 기반 앱에서 프로필 사진을 어디에 어떻게 저장할지 먼저 결정 필요 |
| body 분석 연동 | 최신 `body` 기록의 어떤 필드를 style/predict에 재사용할지 명확히 재정의 필요 |
| 예측/스타일 분리 여부 | `/my-body-style`를 유지할지, 체형 분석 후속 화면 둘로 분리할지 결정 필요 |
