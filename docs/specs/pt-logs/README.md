# PT 수업일지 기능 분해

작성일자: 2026-07-29

## 1. 문서 목적

PT 탭에서 제공하는 `PT 수업일지`와 여기서 이어지는 `AI 추천 트레이너` 기능을 분리해 현재 구현 상태와 남은 제약을 한 번에 이해할 수 있게 정리한다.

이번 문서 묶음은 원본 앱 `2026-07-13/my-PT-Diary`의 회원용 PT 흐름과 `2026-07-13/pt-diary-qa/pt-logs` QA 정리본을 기준으로, 현재 `ai-pt` 작업 트리에 반영된 서버·클라이언트 구현을 기록한다.

## 2. 관련 문서 목록

| 문서 | 다루는 범위 | 현재 상태 | 권장 후속 순서 |
| --- | --- | --- | --- |
| [pt-lessons.md](pt-lessons.md) | PT 수업일지 목록, 날짜 필터, 생성/수정/삭제, 주간 트래커 연동 | 구현 | 1 |
| [trainer-match.md](trainer-match.md) | 트레이너 카탈로그, 인기순/AI 추천순, 상세 모달, 찜, 연결 요청 | 구현 | 2 |

## 3. 범위 해석 기준

| 기준 | 해석 |
| --- | --- |
| 회원 PT 기록 | `x-user-key` 기준으로 분리되는 현재 사용자 데이터다. |
| 트레이너 추천 | 현재는 승인된 시드 트레이너 카탈로그를 기준으로 추천한다. |
| AI 추천순 | LLM 점수화가 아니라 서버 규칙 기반 점수 계산을 말한다. |
| 트레이너 연결 | 현재는 연결 요청 생성과 상태 표시까지를 뜻한다. 실제 수락/배정 워크플로는 후속 범위다. |

## 4. 현재 의사결정이 필요한 포인트

| ID | 항목 | 현재 판단 | 사용자 결정 필요 여부 |
| --- | --- | --- | --- |
| PTLOG-DEC-001 | PT 일지를 운동 리포트 총합에 포함할지 | 현재는 주간 트래커 완료만 연동하고, 운동 리포트 집계에는 포함하지 않는다. | 필요 |
| PTLOG-DEC-002 | 트레이너 연결 요청 승인 후 실제 회원-트레이너 관계를 어디에 저장할지 | 현재는 `trainer_connect_requests` 상태만 저장한다. | 필요 |
| PTLOG-DEC-003 | 추천 사유를 규칙 문구로 유지할지, 이후 LLM 설명을 추가할지 | 현재는 서버 템플릿 문구로 유지한다. | 필요 |
| PTLOG-DEC-004 | 거절된 연결 요청을 재신청 가능하게 할지 | 현재 클라이언트는 재신청 가능처럼 보이지만, 서버는 기존 `rejected` 요청을 그대로 반환한다. | 필요 |
