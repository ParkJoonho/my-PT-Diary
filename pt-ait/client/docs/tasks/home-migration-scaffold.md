# 홈 마이그레이션 스케폴딩

| 작업 | 상태 | 비고 |
| --- | --- | --- |
| 루트 페이지에서 보이는 TODO 보일러플레이트 제거 | 완료 | 루트 페이지가 PT Diary 홈 화면 껍데기를 렌더링하도록 변경했다. |
| 오래된 TODO 산출물 제거 | 완료 | 기존 `todo-app.ait` 샘플 빌드 산출물을 제거했다. |
| 홈 기능 폴더 구조 스케폴딩 | 완료 | 홈 데이터, 타입, 라이브러리, 분리된 컴포넌트를 추가했다. |
| 마이그레이션용 공용 UI 컴포넌트 추가 | 완료 | 재사용 가능한 `UnimplementedBadge` 컴포넌트를 추가했다. |
| 홈 화면 시각 섹션 마이그레이션 | 완료 | 주간 트래커, 루틴 카드, 퀵 카드, 하단 탭바 껍데기를 추가했다. |
| 연결되지 않은 기능에 `미구현` 뱃지 표시 | 완료 | 원본 UI 형태를 대체하지 않고, mock/미연결 컨트롤에 작은 뱃지를 붙였다. |
| 타입 검사 | 완료 | `npm run typecheck`를 통과했다. |
| 린트와 기본 테스트 실행 | 완료 | `npm run lint`를 통과했고, `npm test -- --runInBand`는 테스트 파일 없음 상태로 정상 종료됐다. |
