# Feature Inventory

이 문서는 `src/features` 전체 피처 목록과 구현도 체크리스트다.

체크 상태는 현재 Granite 앱 기준이다. 원본 `my-PT-Diary 프로젝트`의 구현률이 아니라, 이 앱에서 실제로 옮겨졌거나 연결된 정도를 표시한다.

## 체크 기준

- `[x]`: 현재 앱에 구현됐고 기본 검증이 가능하다.
- `[ ]`: 미구현이거나 README/폴더 스캐폴딩만 있다.
- 부분 구현은 체크하지 않고 항목 설명에 `부분:`으로 남긴다. 실제 동작까지 연결되면 체크한다.
- 기능 간 참조는 허용한다. 단, `shared`가 feature를 가져오면 안 된다.

## 구현 축

각 feature는 아래 축으로 구현도를 관리한다.

- UI: 화면, 카드, 탭, 폼, 리스트, 로딩/빈 상태 등 사용자가 보는 구조
- 라우팅: `src/pages`의 Granite route와 feature screen 연결
- 비즈니스 로직: 필터링, 계산, 상태 전이, 입력 검증, 완료 정책
- 저장/동기화: 로컬 저장, 사용자별 분리, 서버 0건/오류 구분, 충돌 정책
- 백엔드/API: 요청/응답 계약, 인증, 에러 처리, 캐시 무효화
- QA/테스트: 타입체크 외 동작 검증, 회귀 테스트, QA 문서 반영
